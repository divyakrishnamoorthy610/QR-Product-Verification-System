# QR Product Verification System

A Java and MySQL based application that uses QR codes to verify registered products.

## Features

- Admin login
- Add, view, update and delete products
- Automatic unique serial number generation
- QR code generation for products
- QR code scanning for product verification
- Product details displayed after successful verification
- MySQL database integration

## Technologies Used

- Java
- MySQL
- JDBC
- Java Swing
- ZXing
- SQL
- Git and GitHub
